# Breast Cancer EDA & Deep Learning

A reproducible academic case study for Exploratory Data Analysis and Visualization using the Wisconsin Diagnostic Breast Cancer dataset.

## Project highlights

- 569 records and 30 numeric predictor features (plus diagnosis label)
- Data quality checks: missing values, duplicates, descriptive statistics and outlier review
- 6 EDA visualizations, each designed to answer a specific question
- Stratified train/validation/test split (70% / 15% / 15%)
- Median imputation and standardization fitted on training data only
- Multilayer Perceptron (MLP) classifier with basic hyperparameter comparison
- 4 model-evaluation visualizations: loss, validation accuracy, confusion matrix and ROC/AUC
- Reproducible Jupyter Notebook and a report in PDF and Word formats

## Important note

This is an educational machine-learning exercise, **not a clinical diagnostic tool**. The model output must not be used to make medical decisions. The reported metrics are specific to the supplied split and random seed; independent external validation would be required before any real-world use.

## Run the notebook

Recommended: Google Colab or Jupyter Notebook.

1. Open `notebooks/breast_cancer_eda_deep_learning.ipynb`.
2. Upload the project folder or place `data/breast_cancer_wisconsin.csv` at the path expected by the notebook.
3. Run cells from top to bottom.
4. The notebook uses Python with pandas, NumPy, Matplotlib and scikit-learn.

Install dependencies if needed:

```bash
pip install pandas numpy matplotlib scikit-learn jupyter
```

## Dataset

The CSV is based on the Wisconsin Diagnostic Breast Cancer dataset distributed by scikit-learn. The original dataset was donated to the UCI Machine Learning Repository. See references in the report and notebook.

## Results from the generated run

- Test accuracy: 95.35%
- Benign-class precision: 94.64%
- Benign-class recall: 98.15%
- Benign-class F1-score: 96.36%
- ROC-AUC (benign score): 0.9936

These results are included for reproducibility and should be regenerated by running the notebook in the target environment.
